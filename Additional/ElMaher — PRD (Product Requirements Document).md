# ElMaher — PRD (Product Requirements Document)

Nov 16, 2026 · @marwan

## 1. الرؤية والهوية

**ElMaher** منصة تعلّم تفاعلي للفيزياء والكيمياء لطلاب الثانوية العامة في مصر، تجمع دروسًا قصيرة تفاعلية وتجارب افتراضية وتدريبًا ذكيًا في مسار واحد، تحت اسم مستر ماهر حمود.

**الاسم:** ElMaher في اللوجو والدومين (مثل elmaher.com، يلزم التأكد من توفره)، و«الماهر» بالعربي، مع عبارة *by Mr. Maher Hamoud* تحت اللوجو. الاسم بدون نقطة لأن النقطة تتعارض مع الدومين وحسابات السوشيال.

**الشعار:** Understand Science. Experience It.

**الفكرة التنافسية:**

- من Brilliant: كل شاشة في الدرس فيها تفاعل، والدرس من 3 إلى 7 دقائق.
- من Duolingo: مسار واضح من عقد (Path)، وسلسلة يومية (Streak)، ودوري أسبوعي، وتذكيرات.
- ما ينفرد به ElMaher: منهج الثانوية العامة المصري، وشرح بالعربي مع المصطلحات الإنجليزية، ومدرس معروف يثق فيه الطالب وولي الأمر.

**الجمهور:** طلاب الصف الأول والثاني والثالث الثانوي (الافتراض الحالي، قابل للتعديل)، مع بنية تسمح بإضافة مواد ومناهج لاحقًا.

## 2. المستخدمون والمشاكل

| المستخدم | هدفه | المشكلة الحالية |
| --- | --- | --- |
| طالب ثانوي | يفهم ويحل ويجيب درجات عالية | الحفظ بدون فهم، وفيديوهات طويلة يصعب الاستمرار فيها |
| ولي الأمر | يتابع مستوى ابنه بوضوح | لا يعرف هل الطالب يذاكر فعلًا ولا نقاط ضعفه |
| مستر ماهر (المدرس) | ينشر محتواه ويتابع الطلاب | أدوات متفرقة، ومتابعة يدوية للأداء والاشتراكات |
| مدير/مشرف | يدير المحتوى والاشتراكات والدعم | تعديل المحتوى يحتاج مبرمجًا |

**أهم ما نحله للطالب:**

- الفهم قبل القانون: يشاهد الظاهرة ويجرب ثم يستنتج.
- الاستمرارية: جلسات قصيرة وسلسلة يومية بدل حصص طويلة.
- معرفة مكان الخطأ بالتحديد، لا مجرد «الإجابة خاطئة».

## 3. مبادئ المنتج ونموذج التعلم

التعلم في ElMaher يتبع مسارًا ثابتًا: **افهم ← جرّب ← استنتج ← حلّ ← أتقن**، والتقدم يعتمد على الإتقان وليس على فتح الدرس.

**مبادئ التصميم:**

1. تفاعل في كل شاشة: سؤال أو سحب أو تجربة، وليس قراءة طويلة.
2. مسار (Path) من عقد: كل عقدة درس قصير + تدريب، وتفتح التالية عند الإتقان.
3. تلميحات تدريجية بدل الإجابة المباشرة، في الدروس والمساعد الذكي.
4. تغذية راجعة تشرح سبب الخطأ (قانون غير مناسب، وحدات، تعويض، إشارة).
5. التحفيز يكافئ الفهم والإتقان، لا الضغط على الأزرار.
6. الموبايل أولًا، والعربية (RTL) كاملة.

**قالب العقدة (الدرس):**

| الخطوة | المحتوى |
| --- | --- |
| 1. مقدمة | الظاهرة أو التجربة الكيميائية في سؤال أو موقف |
| 2. شرح بصري | رسم أو حركة أو جزيء 3D |
| 3. تجربة تفاعلية | سليدرز ومتغيرات ونتائج لحظية |
| 4. القانون/القاعدة | معنى الرموز والوحدات |
| 5. أمثلة محلولة | تدرج في الصعوبة |
| 6. تدريب | أسئلة تطبيق مع تلميحات |
| 7. تحدي الدرس | سؤال قصير للتأكد |
| 8. فحص الإتقان | يحدد فتح العقدة التالية |

## 4. متطلبات المنتج حسب النظام

الأولوية: **P0** لازم في أول إطلاق، **P1** بعد الإطلاق التجريبي.

### 4.1 الأكاديمية والمسار (Academy & Path)

- P0: مواد (فيزياء، كيمياء) ← صفوف ← وحدات ← دروس، مع مسار عقد يفتح بالإتقان.
- P0: حفظ تلقائي لمكان الطالب في الدرس.
- P1: مراجعة ذكية تعيد عقد الضعف للمسار.

### 4.2 المعمل العلمي (Science Lab)

| المادة | أمثلة التجارب | الأداة |
| --- | --- | --- |
| فيزياء | المقذوفات، قوانين نيوتن، الدوائر الكهربية، تداخل الموجات | Matter.js وCanvas وThree.js |
| كيمياء | موازنة المعادلات، المعايرة (Titration)، الجدول الدوري التفاعلي، عارض جزيئات 3D، الاتزان وpH | Three.js أو 3Dmol.js وSVG |

- P0: 5 تجارب فيزياء و5 كيمياء كحد أدنى في الإطلاق، كل تجربة بسليدرز وقيم لحظية ورسم بياني وسؤال استنتاج.
- كل التجارب افتراضية بالكامل، بدون خطوات لتحضير مواد خطرة.

### 4.3 مركز التدريب (Practice Center)

- P0: بنك أسئلة حسب الصف والوحدة والدرس والصعوبة: اختيار من متعدد، رقمية، مفاهيمية، رسوم بيانية، موازنة معادلات.
- P0: تصحيح تلقائي مع شرح، وتصنيف الخطأ (قانون، تعويض، وحدات، إشارة، حساب).
- P0: عرض المعادلات الكيميائية والرياضية بـ KaTeX مع mhchem (مثل H₂SO₄ و Fe³⁺).
- P1: اختبارات بوقت، وإعادة تدريب على الأخطاء.

### 4.4 المساعد الذكي (AI Tutor)

- P1: يشرح بالعربية مع المصطلحات الإنجليزية، ويستخرج المعطيات والمطلوب، ويعطي تلميحات تدريجية.
- التحقق: الحسابات والأوزان الذرية والوحدات تُراجع بكود وجداول موثوقة، لا بالاعتماد على النموذج وحده.
- حد استخدام يومي حسب الخطة، وتسجيل المحادثات لمراقبة الجودة.

### 4.5 التقدم والإتقان (My Progress)

- P0: نسبة الإكمال، النتائج، خريطة إتقان لكل موضوع (لم يبدأ / يحتاج تدريبًا / جيد / متقن).
- P1: الأخطاء المتكررة، ووقت التعلم، والتقدم الأسبوعي والشهري.

### 4.6 التحفيز (Gamification)

- P0: XP وسلسلة يومية (Streak) وشارات.
- P1: دوري أسبوعي (Leagues) وتحديات أسبوعية، مع تذكيرات.
- القاعدة: الـ XP على الإتقان والتحسن، وليس على عدد الضغطات.

### 4.7 لوحة ولي الأمر (Parent View)

- P1: ربط حساب ولي الأمر بالطالب، وتقرير أسبوعي مبسط (الدروس، النتائج، نقاط الضعف).

### 4.8 العضوية والاشتراكات (Membership)

| الخطة | المحتوى |
| --- | --- |
| Free | دروس مختارة، تدريب أساسي، محاكاة محدودة، تقدم أساسي |
| Premium | كل المسارات والمعامل، بنك أسئلة موسع، تحليل أخطاء، مساعد ذكي بحصة أكبر، تقارير متقدمة |

- P0: تفعيل يدوي وأكواد اشتراك (للمراكز والكتب) كحل أساسي في البداية.
- P1: بوابة دفع مصرية بعد فحص شروطها وأسعارها، وكوبونات وتجديد وسجل مدفوعات.
- الأسعار تُحدد لاحقًا.

### 4.9 لوحة الإدارة (Admin Studio)

- P0: إدارة الصفوف والوحدات والدروس والأسئلة والتجارب، ورفع الوسائط، والنشر والإخفاء، وإدارة الطلاب والاشتراكات.
- P1: أدوار منفصلة (Super Admin وContent Manager وSupport)، وإحصائيات الاستخدام، وسجل تدقيق (Audit Log) وإعلانات وإشعارات.

## 5. الصفحات ورحلات المستخدم

| الصفحة | الوصف |
| --- | --- |
| Home | تعريف بالمنصة والمدرس، ومعاينة تفاعلية، وزر التسجيل |
| About | عن مستر ماهر حمود ومنهجه |
| Subjects | اختيار فيزياء أو كيمياء ثم الصف |
| Path | مسار العقد للمادة والصف |
| Interactive Lesson | الدرس بشاشاته التفاعلية |
| Science Lab | مكتبة التجارب الافتراضية |
| Practice Center | الأسئلة والاختبارات ومراجعة الأخطاء |
| AI Tutor | المحادثة مع المساعد |
| My Dashboard | التقدم والإتقان والسلسلة اليومية |
| Parent View | تقرير ولي الأمر |
| Pricing | مقارنة Free وPremium وتفعيل كود |

**رحلة الطالب:**

1. يسجل ويختار الصف والمادة.
2. يدخل مسار المادة ويبدأ أول عقدة.
3. يمر بالدرس التفاعلي والتجربة.
4. يحل التدريب ويحصل على تغذية راجعة.
5. يعبر فحص الإتقان فتفتح العقدة التالية ويكسب XP.
6. يعود يوميًا للحفاظ على السلسلة ومراجعة نقاط الضعف.

**رحلة التفعيل (Beta):** دعوة أو كود ← إنشاء حساب ← تفعيل Premium يدويًا أو بالكود ← الوصول للمحتوى الكامل.

## 6. البنية التقنية

نبدأ بتطبيق ويب واحد (PWA) يخدم الطالب وولي الأمر والإدارة، وخلفه خدمات منفصلة يسهل استبدالها.

&#91;embedded content: system architecture · app, backend, 4 services\]

كل الطلبات تمر عبر الخلفية، فلا تتصل الواجهة بقاعدة البيانات أو الذكاء الاصطناعي أو الدفع مباشرة.

| الجزء | التقنية المقترحة |
| --- | --- |
| الواجهة | Next.js + TypeScript + Tailwind CSS + Framer Motion |
| محاكاة فيزياء | Matter.js (2D) وThree.js (3D) |
| محاكاة كيمياء | Three.js أو 3Dmol.js للجزيئات، وSVG للمعايرة والجدول الدوري |
| المعادلات | KaTeX مع mhchem للمعادلات الكيميائية |
| الخلفية | Next.js API أو NestJS |
| قاعدة البيانات | PostgreSQL + Prisma |
| الحسابات | Auth.js |
| الذكاء الاصطناعي | LLM API خلف طبقة تحكم وتحقق |
| النشر | Vercel أو استضافة مناسبة |

**متطلبات غير وظيفية:**

- موبايل أولًا، وPWA قابلة للتثبيت، مع توفير بيانات لأن الإنترنت غير ثابت عند بعض الطلاب.
- RTL كامل، وعرض صحيح للرموز العلمية والمعادلات داخل النص العربي.
- حفظ تلقائي لتقدم الطالب.
- مفاتيح AI والدفع على الخادم فقط، وصلاحيات واضحة لكل نوع مستخدم.
- نسخ احتياطية يومية واختبارات دورية.
- الحلول الحسابية تُتحقق بقواعد رياضية واختبارات، لا بالذكاء الاصطناعي وحده.

## 7. نموذج البيانات

المادة (subject) كيان أساسي، فيضاف أي علم جديد لاحقًا بدون إعادة بناء القاعدة.

| المجموعة | الجداول الأساسية |
| --- | --- |
| الحسابات | users, profiles, roles, parent\_links |
| المنهج | subjects, grades, units, lessons, path\_nodes |
| المحتوى | lesson\_blocks, media, resources |
| التدريب | questions, choices, solutions, error\_types |
| التقييم | quizzes, attempts, answers |
| التقدم | lesson\_progress, mastery, activity\_logs |
| المعمل | simulations, simulation\_results |
| الذكاء الاصطناعي | conversations, tutor\_messages, usage\_limits |
| التحفيز | xp\_transactions, achievements, streaks, leagues |
| العضوية | plans, subscriptions, payments, coupons, activation\_codes |
| الإدارة | announcements, audit\_logs, settings, invitations |

**العلاقة المحورية:** الطالب له صف ومواد واشتراك ومحاولات وتقدم وإنجازات واستخدام للمساعد الذكي، وولي الأمر مرتبط بالطالب للقراءة فقط.

نصل للمنتج الكامل على مراحل قابلة للاختبار، وبوابة Beta تفصل بين البناء والإطلاق العام. المدد تتحدد بعد حسم الصفوف وحجم المحتوى.
