# ElMaher — الدفعة الأولى من الكود

كود جاهز يتنسخ داخل مشروعك على نفس هيكل المجلدات اللي عندك. اتكتب واتختبر في بيئة بدون إنترنت، فمفيش حاجة هنا اتشغلت داخل Next.js فعليًا (شوف "اللي لم يُختبر").

## 1) النسخ (من غير استبدال أي ملف موجود)

انسخ مجلد `src/` داخل `src/` عندك. المجلدات متطابقة (`features/academy`, `features/practice`, `features/gamification`, `features/science-lab/...`, `components`, `types`, `app`).
ملفات `scaffold/` (`next.config.ts`, `postcss.config.mjs`, `tsconfig.json`) انسخها للجذر **فقط لو مش موجودة**.

أضف في `package.json`:

```json
"scripts": {
  "dev": "next dev",
  "build": "next build",
  "start": "next start",
  "test": "tsx --test tests/core.test.ts tests/content.test.ts"
}
```

ثم `npm run dev` وافتح `http://localhost:3000`. انسخ مجلد `tests/` (ملف `ssr.test.tsx` اختياري، محتاج stub لـ next/link، تجاهله).

## 3) إزاي الطالب مش بيزهق (ومبني في الكود)

- كل شاشة فيها تفاعل، والدرس 4 إلى 5 دقائق، والتدريب جولات من 8 أسئلة.
- **نقاط فورية** على كل إجابة صح: أساس 10 (5 للمحاولة الثانية) + مكافأة سرعة حتى 5 + **كومبو** يضاعف حتى ×2. التلميح يخصم قليلًا.
- **لا عقاب**: مفيش قلوب ولا قفل. الغلط يصفّر الكومبو فقط، والنجوم لا تقل عن 1.
- **صعوبة تكيّفية**: 3 صح من أول مرة تصعّب، ومرتان غلط تسهّل، فالطالب يفضل في منطقة التحدي.
- **تنوع**: المواضيع الضعيفة تتكرر أكتر، ولا يتكرر نفس الموضوع مرتين ورا بعض.
- **أرقام عشوائية** في كل مرة، فإعادة الدرس مش نسخة مكررة.
- **ستريك يومي** مع "تجميد" (يحمي من يوم غياب، ويُكسب كل 7 أيام)، **هدف يومي** 50 XP، **مستويات**، **9 شارات**.
- رسائل التحفيز والتغذية الراجعة بتقول **سبب الخطأ** مش بس "غلط".

كل أرقام الدرجات في ملف واحد (`gamification/engine.ts`) وسهل تعديلها.

## 4) اللي لم يُختبر (لازم تجربه عندك)

- **لم يُشغَّل داخل Next.js ولا متصفح.** اختبرت المنطق (35 اختبار ناجح + فحص أنواع صارم) والمكوّنات بعرض الخادم (SSR) فقط. التفاعلات (الضغط، السلايدرز، الأنيميشن، الكانفاس) تحتاج تجربة يدوية أو Playwright.
- ملفات `.tsx` لم تُفحص بأنواع React (مفيش `@types/react` عندي). شغّل `npx tsc --noEmit` عندك.
- `katex/contrib/mhchem`: تأكد أن مسار الاستيراد يعمل مع إصدار KaTeX عندك (0.19.1). اختبرته على 0.16.
- الخط Cairo يتحمّل من Google وقت البناء (يحتاج إنترنت).
- Next 16: صفحة الدرس تستخدم `params` كـ Promise. لو ظهر تحذير عدّل حسب رسالة Next.

## 5) محتاج قرار أو تجهيز

- الدروس **نماذج**. المحتوى الفعلي والترتيب حسب كتاب الوزارة يراجعه مستر ماهر.
- التقدم محفوظ في `localStorage` (على جهاز الطالب فقط). الخطوة التالية: ربطه بـ Prisma/PostgreSQL والحسابات.
- Premium هنا مجرد قفل شكلي (زر dev في وضع التطوير). التفعيل الحقيقي لازم يكون على الخادم.
- لم أبنِ بعد: معمل نيوتن (المنطق جاهز في `physics.ts`)، صفحة التقدم، المدرس الذكي، لوحة الإدارة، الدوري الأسبوعي.
- `npm audit`: لا تستخدم `--force`. أغلب التحذيرات في أدوات dev (glob/minimatch/serwist). ابدأ بـ `npm audit fix` العادي وراجع الباقي.
